## 🧭 Краткий обзор

**Краткий профиль:** Я будущий специалист по разработке приложений с опытом в веб-дизайне и графическом дизайне. Мой фокус — современная веб-разработка, приложения с ИИ, SaaS-проекты и практическая разработка ПО. Я активно использую ИИ для планирования, понимания кода, поиска ошибок, рефакторинга, документации и структурированной разработки.

- Обучение: будущий специалист по разработке приложений (IHK Штутгарт)
- Фокус: AI-FIRST Development, современная веб-разработка, SaaS и приложения с ИИ
- Практика: собственные SaaS- и клиентские проекты с четкой структурой и документированными процессами
- Подход: планирование с ИИ, дебаггинг, рефакторинг и чистая документация
- Опыт: веб-дизайн и графический дизайн для последовательного UI/UX и ясной коммуникации
